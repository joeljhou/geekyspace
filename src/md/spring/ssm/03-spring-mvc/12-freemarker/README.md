# 模板引擎

介绍模板引擎将数据与模板组合的作用，并整理 JSP、FreeMarker 和 Thymeleaf 等方案。

## 模板引擎的介绍

模板引擎将数据填入模板，生成最终页面，即“数据 + 模板 = 结果”。

![模板引擎的介绍](https://img.geekyspace.cn/pictures/2026/202610271647663.png)

## 主流模板引擎

- Java Server Page - J2EE 组件
- FreeMarker - 独立的 Java 模板引擎
- Beetl - 后起之秀
- Thymeleaf - Spring Boot 常用的服务端模板引擎
