## 2. IDEA 介绍

IntelliJ IDEA 是面向 Java 开发的集成开发环境，提供代码补全、智能提示、重构、代码检查、测试工具集成和 Java Web 开发支持。

## 4. IDEA 的主要优势

- 集成 Git、Maven、Spring 等常用工具。
- 提供快速、覆盖范围广的代码提示。
- 支持快捷键和代码模板，例如 `psf` 可生成 `public static final`。
- 支持精准搜索和代码导航。
