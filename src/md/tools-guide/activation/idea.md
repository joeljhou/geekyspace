## 2. 命令行一键激活

- **网站**：[ckey.run](https://ckey.run/)
- **原文**：[LINUX DO 一键激活教程](https://linux.do/t/topic/694120)

### Windows

打开 **PowerShell（管理员）**，按需执行以下命令。

**激活**

```powershell
irm ckey.run|iex
```

**调试**

```powershell
irm ckey.run/debug|iex
```

**取消激活**

```powershell
irm ckey.run/uninstall|iex
```

### Linux

打开终端，按需执行以下命令。

**激活**

```bash
wget -q ckey.run -O ckey.run && bash ckey.run
```

**调试**

```bash
wget -q ckey.run/debug -O ckey.run && bash ckey.run
```

**取消激活**

```bash
wget -q ckey.run/uninstall -O ckey.run && bash ckey.run
```

### macOS

打开终端，按需执行以下命令。

**激活**

```bash
curl -Ls ckey.run -o ckey.run && bash ckey.run
```

**调试**

```bash
curl -Ls ckey.run/debug -o ckey.run && bash ckey.run
```

**取消激活**

```bash
curl -Ls ckey.run/uninstall -o ckey.run && bash ckey.run
```
