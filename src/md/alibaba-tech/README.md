## 前端与跨端基础

1. [前端工程之美](./01-frontend-engineering.md)：从依赖管理、语言特性、框架、Node.js 与浏览器能力出发，理解现代前端工程为何需要这些工具。
2. [Flutter 入门指南](./02-flutter.md)：搭建 Flutter 与 Android / iOS / macOS 工具链，掌握常用命令、Widget、生命周期、页面跳转和网络请求的入门要点。

## 工程卓越之旅

1. [可落地的整洁代码](./engineering-excellence/01-clean-code.md)：以简单设计为起点，在测试保护下重构，结合编码规约、架构演进、代码评审和持续集成，让代码长期可维护。
2. [技术文档该怎么写](./engineering-excellence/02-technical-writing.md)：明确读者与目标，通过准备、调研、组织、撰写、审阅和发布六个阶段，沉淀能被找到、理解和持续使用的知识。
3. [手把手教你单元测试](./engineering-excellence/03-unit-testing.md)：区分测试层次，运用 JUnit、Mockito 与四大步骤、八大方法，通过正数判断、矩形面积和保存用户案例验证业务行为。
4. [玩转代码评审](./engineering-excellence/04-code-review.md)：理解评审价值与检查重点，从开发者和评审者两端降低协作成本，形成小变更、早反馈、自动化检查的研发习惯。

## 如何阅读

- **想了解终端开发**：先读前端工程建立技术栈全貌，再按需学习 Flutter；两者不是必须依次完成的先修课程。
- **想改善工程质量**：按整洁代码 → 技术文档 → 单元测试 → 代码评审的顺序阅读。先建立质量与设计意识，再把规则落到知识沉淀、自动验证和团队协作。
- **按当前问题查阅**：代码难改看整洁代码，交接困难看技术文档，不敢重构看单元测试，合入低效看代码评审。
